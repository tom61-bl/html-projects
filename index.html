About This Collection

Philosophy

Every project in this collection is a single, self-contained HTML file. No build tools, no npm install, no framework — just open it in a browser and it works. This constraint forces clarity: the code you see is the code that runs.

These projects were built as experiments in interaction design, game mechanics and educational technology. The pixel game went through four major iterations (from a simple prototype to an isometric Stardew-Valley-style RPG). The communication trainer evolved into a full-featured learning app with gamification.

The source code lives on GitHub. Feel free to fork, modify or use any part of these projects.
